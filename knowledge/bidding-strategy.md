## Objective → Recommended Bidding

| Objective | Bidding แนะนำ | Budget ขั้นต่ำ/วัน |
|---|---|---|
| Friend Added | CPF Auto | ฿100 |
| Website Clicks | CPC Auto | ฿100 |
| Conversion | Target CPA (ถ้ามี tracking) / CPC | ฿300 |
| Reach | CPM Auto | ฿50 |
| App Install | CPC Auto | ฿100 |
| Video Views | CPV Auto | ฿50 |

## เมื่อไรใช้ Manual Bid

```
ใช้ Auto ก่อนเสมอ (2–3 วันแรก)
Switch ไป Manual ถ้า:
  - ใช้จ่ายไม่ครบ budget (underspend)
  - CPC/CPF สูงกว่าที่รับได้มาก
  - ต้องการ control ราคาเพดาน
```

## Learning Phase

```
ช่วง Learning: 7–14 วันแรก
ระหว่าง Learning:
  - ห้ามเปลี่ยน targeting / bidding บ่อย
  - ห้ามเพิ่ม budget เกิน 20%/วัน
  - ผลลัพธ์อาจผันผวน — ปกติ

สถานะ "กำลังเรียนรู้" ใน LINE Ads → รอ 14 วันก่อนตัดสิน
```
