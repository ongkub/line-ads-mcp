## วิธีใช้กับ Customer Avatar (Need / Ability / Life Stage)

App behavior คือ **สิ่งที่คนทำจริงบนมือถือ** ไม่ใช่แค่ความสนใจ จึงใช้ "เติม" แต่ละชั้นให้หนาขึ้น (OR ในชั้น) ไม่ใช่เพิ่มเป็นชั้นใหม่ที่ AND ซ้อนจนแคบ

| ชั้น | ใช้ app code แบบไหน | ตัวอย่าง |
|---|---|---|
| **Need** | หมวดหมู่แอป/persona ที่ตรงกับปัญหาที่สินค้าแก้ (signal สูงเท่านั้น) | ท่องเที่ยว → `2479` + `2435`; คอร์ส → `2469`; B2B/SaaS → `2474`; creator tools → `2466` |
| **Ability** | ระดับความมั่งคั่ง + ราคามือถือ (proxy กำลังซื้อที่แม่นกว่า interest การเงิน) | premium → `2444` `2445` `2450`; ราคาประหยัด → `2442` `2446` |
| **Life Stage** | persona ที่บอกช่วงชีวิต | มีลูกเล็ก → `2436`; เกษียณ → `2439`; รถคันแรก → `2441` |

กฎ:
- ห้ามใช้หมวดที่ signal ต่ำ (`2468` `2470` `2476` `2477` `2478`) เป็น code หลักของชั้น Need — แทบทุกคนมีแอปพวกนี้ ใส่ไปก็ไม่ได้คัดใคร
- อย่าเลือกระดับความมั่งคั่ง/ราคามือถือทุกระดับพร้อมกัน — เท่ากับไม่ได้ filter
- `2451`/`2452` และ `2453`/`2454` ซ้อนกัน เลือกช่วงเดียวต่อชั้น
- ยังต้องเช็ค `get_adset_audience_size` หลังสร้างตามปกติ — ชั้น Ability ที่ใช้ `2445` (1.5M) AND กับ Need กลุ่มเล็กอาจแคบเกินงบ

## ตัวอย่าง Avatar ที่ใช้หมวดหมู่แอป

**ทัวร์/โรงแรมระดับกลาง-บน — คนชอบเที่ยว มีกำลังซื้อ**

```python
interest_groups=[
    ["18", "2479", "2435", "1783", "1871"],   # Need: ท่องเที่ยว + แอปท่องเที่ยว + ชอบเดินทาง + OpenChat/LINE TODAY ท่องเที่ยว
    ["2443", "2444", "2445", "2449", "2450"],  # Ability: มั่งคั่งกลางขึ้นไป + มือถือ 30k+
]
```

**คอร์สออนไลน์อัปสกิลคนทำงาน**

```python
interest_groups=[
    ["9", "2469", "1788", "2474"],             # Need: การศึกษา + แอปการศึกษา + เรียนรู้พัฒนาตนเอง + แอปทำงาน
    ["2443", "2444", "2445", "1590"],          # Ability: มั่งคั่งกลางขึ้นไป + กำลังซื้อสูง
]
```

**สินค้าแม่และเด็ก**

```python
interest_groups=[
    ["1019", "1636", "1777", "2436"],          # Need + Life Stage: การเลี้ยงดู + OA เด็กอ่อน + OpenChat เลี้ยงดูบุตร + แม่และเด็ก (app)
    ["2443", "2444", "2445"],                  # Ability: มั่งคั่งกลางขึ้นไป
]
```

**โชว์รูมรถ — ลูกค้ารถคันแรก**

```python
interest_groups=[
    ["12", "2441", "1772"],                    # Need: รถยนต์ + สนใจซื้อรถคันแรก + OpenChat ยานยนต์
    ["2443", "2444", "2448", "2449"],          # Ability: มั่งคั่งกลาง-สูง + มือถือ 20-40k
]
```
